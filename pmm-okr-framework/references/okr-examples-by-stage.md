## OKR Scoring Reference

| Score | Meaning |
|---|---|
| 1.0 | Fully achieved — consider whether target was ambitious enough |
| 0.7–0.9 | Strong performance — healthy zone for stretch OKRs |
| 0.5–0.7 | Partial progress — investigate blockers; some value delivered |
| < 0.5 | Missed — diagnose: bad target, bad execution, wrong assumption? |

> A PMM team consistently scoring 0.7 on ambitious OKRs is outperforming one that scores 1.0 on safe ones.
