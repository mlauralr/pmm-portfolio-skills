# PMM Portfolio Skills

Custom Claude skills built for my fictitious PMM portfolio project (EnergyFlow Renewables). This is the full 14-skill system referenced in my portfolio site: 4 foundational context-building skills (ICS, personas, positioning, messaging), a campaign orchestration skill, sales-enablement and demand-gen/nurture/content skills, competitive intelligence skills, and a consistency-check skill that gates every deliverable.

| # | Skill | What it does |
|---|---|---|
| 1 | `pmm-okr-framework` | Outcome-driven PMM OKRs tied to revenue, adoption, or competitive position |
| 2 | `b2b-ics-framework` | Defines and prioritizes ideal customer segments |
| 3 | `b2b-persona-framework` | Builds buying-committee personas (JTBD, decision behavior) |
| 4 | `b2b-positioning-framework` | Builds positioning from scratch (market frame, differentiation) |
| 5 | `b2b-messaging-framework` | Translates positioning into a full messaging system |
| 6 | `pmm-campaign-brief-to-plan` | Turns a launch objective into a full execution plan |
| 7 | `b2b-battlecard-generator` | Sales-ready battlecard for a named competitor |
| 8 | `pmm-campaign-demand-gen` | Demand generation campaign (targeting, channels, calendar, funnel) |
| 9 | `pmm-content-calendar` | Monthly editorial calendar across LinkedIn, email, blog |
| 10 | `pmm-campaign-nurture` | Nurture email sequence (copy, timing, branching, exit conditions) |
| 11 | `pmm-competitive-update` | Reactive workflow for a specific competitive move |
| 12 | `b2b-win-loss-analysis` | Synthesizes win/loss interviews and CRM data into patterns |
| 13 | `b2b-case-study-generator` | Outcome-driven case study from customer results |
| — | `pmm-consistency-check` | Gate skill — checks every deliverable against approved messaging/positioning |

Built and used with [Claude](https://claude.com) as part of a self-directed applied AI / PMM learning project. See the full portfolio and methodology at [my portfolio site].
