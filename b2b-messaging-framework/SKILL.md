# B2B Messaging Framework

Messaging is the translation layer between product truth and buyer behavior. If it doesn't change what Sales says on a call or what Marketing publishes on a page, the framework isn't finished.

## Step 0: Gather context

| Input | Why it matters |
|---|---|
| Product positioning | Foundation — messaging makes positioning executable |
| Target ICP and personas | Messaging must speak to specific buyers, not a generic market |
| Primary jobs to be done | Messaging anchors in the job, not the feature |
| Competitive landscape | Shapes differentiation and objection handling |
| Sales motion | Determines which channels and formats matter most |
| Key differentiators and proof points | Raw material for value pillars |

If positioning doesn't exist yet, extract it from the product description and customer context, and state the inferred positioning explicitly before building messaging on top of it.

## Method: five layers

Full detail and the complete output template are in `references/methodology.md`.

1. **Core narrative foundation** — the internal logic (old way vs. new way, category frame, why now) that makes every downstream message coherent. Not customer-facing copy itself.
2. **Value pillars** — 2-4 outcome-driven themes, each with a benefit statement, supporting explanation, business impact, and the feeling it delivers. "Predictive maintenance module" is a feature; "catching a failing inverter before it costs three days of production" is a pillar.
3. **Proof system** — map each pillar to the evidence that makes it credible: customer outcomes, benchmarks, case studies, credibility signals.
4. **Persona-based messaging** — the same value translated through each buyer's job, KPIs, and fears (see the persona table in the reference for economic, technical, and functional buyer angles suited to a renewable-energy asset management sale).
5. **Objection-aware messaging** — the five most common resistance patterns, each with its root cause and a response, not a rebuttal script to memorize but a reframe grounded in evidence.

## Output

A core messaging statement, the five layers above, and a channel adaptation guide (website, sales, marketing/demand gen, product/onboarding) showing how the same pillars get expressed differently per channel without changing what they mean. Close with a short validation section: one measurable signal per pillar (reply rate by message angle, demo-to-proposal conversion, trial activation tied to a specific pillar) so the framework can be checked against reality instead of just approved and forgotten.

## Guardrails

- Outcome-driven, not feature-driven, throughout.
- Avoid ungrounded superlatives ("seamless", "best-in-class") — if a claim needs proof and has none, mark it as a gap to fill, not a placeholder to ship.
- The core message must be traceable through every persona and channel adaptation; personas get different emphasis, not different stories.
- If a marketing manager can't use a pillar to write a landing page, or a rep can't use it in a cold email, it isn't done.

## Advanced options

If requested: a full homepage rewrite, a slide-by-slide sales deck narrative, a campaign messaging calendar, or product onboarding UX copy — all derived from the pillars above rather than written independently.
